#Taller-Java-Backend---Gesti-n-de-Estudiantes-Cursos-y-Matriculas

Sistema de gestión académica desarrollado en Java para la administración de estudiantes, cursos y sus respectivas matrículas. Este proyecto fue diseñado como parte de un taller práctico de desarrollo backend.

🚀 Características principales:

Gestión de Estudiantes: Registro, edición, eliminación y consulta de datos de estudiantes.
Gestión de Cursos: Creación y asignación de materias o cursos académicos.
Control de Matrículas: Inscripción de estudiantes a cursos y validación de cupos o estados.

🛠️ Tecnologías utilizadas:

Lenguaje: Java (JDK 21)
Construcción y Dependencias: Apache Maven
